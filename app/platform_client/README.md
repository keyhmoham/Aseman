# A platform's lightweight client

The Android app a platform gets when it publishes an Elpian frontend
(docs/PLATFORM.md §8.3): the Elpian engine, the UI kit and the Elpian host
the Aseman client runs frontends with, plus what it needs to reach Aseman —
the platform's public description, sign-in to the platform's own accounts,
and the wake door. Nothing else of Aseman: no workspace, no messenger, no
Elpian VM native library (a platform's frontend runs on QuickJS), no Godot
(a 3D scene shows its placeholder).

| Here | What |
|---|---|
| `lib/client/config.dart` | what this build is for: `assets/client.json` (`node`, `platform`, `name`, `frontend`, `accent`) or `--dart-define=ASEMAN_FRONTEND_URL=…` |
| `lib/client/node_api.dart` | the node: `developer.platform_frontend`, `auth.login` / `register` / `logout` with `platform`, and `<frontend>_aseman/wake` |
| `lib/client/wake.dart` | wakes the platform's computer when the app opens, comes back to the foreground, or the frontend answers 503 — one wake at a time |
| `lib/client/frontend_view.dart` | the frontend's Elpian program, full screen, on the app's own `ElpianAppHost` |
| `lib/client/client_app.dart`, `account_sheet.dart` | the app: waking, the frontend, a menu to reload and sign in or out |
| `tool/shared.txt` | the app sources this client shares (generated by `tool/shared_closure.py`) |
| `tool/assemble.sh` | copies them (and the Elpian fonts) in from `app/` |

The shared sources are never kept here: they are the app's, copied in when
the client is assembled, so the engine is always the Aseman client's own.

## Develop

```bash
tool/assemble.sh                 # lib/src and assets/elpian from ../lib, ../assets
flutter pub get
flutter analyze && flutter test
flutter run --dart-define=ASEMAN_FRONTEND_URL=http://10.0.2.2:8080/v1/platforms/acme/app/
```

After changing what the client uses from the app, run
`python3 tool/shared_closure.py` (CI-style check: `--check`).

## Build for a platform

The node does it: `platform_publish` (agents) or **Developer API → Platforms
→ Android app → Build** (console) runs, on the frontend space's computer,

```bash
aseman-platform-client build --frontend https://node.example/v1/platforms/acme/app/ \
  --name Acme --out /workspace/.aseman/platform-clients/acme/acme.apk \
  --state /tmp/aseman-platform-client/acme
```

(`deploy/sandbox-computer/platform-client`), stores the APK on the node and
serves it at `/v1/platforms/acme/client/android.apk`. The sandbox image
carries this client assembled (`/opt/aseman-platform-client`; built with
`--build-context aseman-app=app`).
